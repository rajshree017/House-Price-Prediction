# 🏠 House Price Prediction

Machine Learning project to predict house prices using Linear Regression.

## 📊 Analyses Performed
- Price Distribution (Histogram + Box Plot)
- Correlation Heatmap
- Top Features vs Price
- Actual vs Predicted Results
- Feature Importance

## 🤖 ML Model
- Linear Regression
- R² Score, MAE, RMSE metrics
- StandardScaler for feature scaling
- 80/20 Train-Test Split

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn

## ▶️ How to Run
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
python house_price_prediction.py
```

## 📁 Output
5 charts saved as PNG files automatically.
